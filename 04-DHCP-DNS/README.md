# Cisco Packet Tracer Project #04 - DHCP & DNS

## Overview
Implementasi DHCP Server & DNS Server pada topologi Inter-VLAN Routing untuk otomatisasi IP management di jaringan enterprise kecil.

## Project Objectives
- Konfigurasi DHCP Pool untuk 3 VLAN berbeda
- Konfigurasi DNS Server untuk resolve nama lokal
- Integrasi dengan Router-on-a-Stick

## Verification
- `ipconfig /all` di PC Client dapat IP otomatis
- `nslookup cisco.local` berhasil resolve

## Skills Demonstrated
CCNA | DHCP | DNS | Cisco Packet Tracer | Troubleshooting
